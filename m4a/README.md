# Recursos de Audio | COS Launcher

Los archivos de audio incluidos en este directorio son recursos sonoros exclusivos desarrollados e integrados por **Austin González** para el proyecto **COS Launcher**:

- `cos_launcher_background.m4a`: Pista musical de fondo oficial integrada en el reproductor interactivo.
- `click_1.m4a`: Efecto sonoro de pulsación / interacción táctil para elementos interactivos.
- `click_2.m4a`: Efecto sonoro de retroceso / cierre para ventanas y visores modales de capturas.
- `juegoabrir.mp3`: Efecto sonoro de apertura y lanzamiento ejecutado al ampliar capturas de la galería e interfaz.
